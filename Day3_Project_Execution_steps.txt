## Module 1 — Licious Prometheus Lab


open -a Docker   # if not already running
docker start kafka-kafka-1
cd "/Users/venkatesh/Performance Engineering & Monitoring tools/licious-prometheus-lab"
docker compose -f prometheus/docker-compose.yml up -d
source venv/bin/activate && uvicorn main:app --port 8008

```
Open `http://127.0.0.1:8008` (app) and `http://localhost:9090` (Prometheus).
```
